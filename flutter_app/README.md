# Flutter E-Commerce Application

Complete cross-platform mobile application for the Ecomdev Laravel backend.

## Getting Started

1. Install dependencies:
   ```bash
   flutter pub get
   ```

2. Run the application:
   ```bash
   flutter run
   ```

Refer to the main [FLUTTER_GUIDE.md](../FLUTTER_GUIDE.md) in the project root for full architecture details and backend URL setup.
